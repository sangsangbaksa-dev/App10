# 세금적립

프리랜서·1인 사업자를 위한 **종합소득세 적립 계산기**입니다. 수입과 경비를 기록하면 적립 목표와 원천징수 차감분을 한눈에 보여줍니다.

## 기능

- 수입/경비 기록 (날짜, 금액, 거래처, 메모, 3.3% 원천징수 여부)
- 연도별 요약: 총수입, 총경비, 순수입, 적립 목표, 원천징수 누계, 추가 적립 필요액
- 적립률 설정 (기본 15%, 0~60%)
- 종합소득세 정기 신고 마감(다음 해 5월 31일)까지 D-day 표시
- 월별 집계 (행 클릭 시 해당 월만 표시)
- 수정·삭제, 전체 삭제 (확인 창 포함)
- CSV 내보내기 (BOM 포함, 수식 주입 방지)
- **AI 분석 (선택)**: 적립 상황을 쉬운 말로 설명하고 매달 적립액을 제안합니다. 키가 없어도 같은 형식의 기본 분석이 항상 보입니다.

## AI 분석 (선택 기능)

적립 상황을 쉬운 한국어로 풀어 설명하고, 남은 달 수에 맞춘 **매달 적립 권장액**과 조언 최대 3개를 보여줍니다.

- **키가 없을 때**: `logic.js`의 `localTaxAdvice()`가 같은 계산 결과로 규칙 기반 설명을 만듭니다. 항상 보이며 네트워크를 쓰지 않습니다.
- **키가 있을 때**: 「AI로 분석하기」를 누르면 브라우저가 `https://api.anthropic.com/v1/messages`를 직접 호출합니다 (모델 `claude-haiku-5-5`). 응답은 JSON으로만 받아 검증하며, 형식이 맞지 않으면 기본 분석으로 대신합니다.
- 기록을 바꾸면 이전 AI 결과는 숨겨지고 다시 분석하라는 안내가 뜹니다.

### API 키 넣는 법

1. Anthropic 콘솔에서 API 키를 만듭니다 (`sk-ant-...`).
2. 화면 아래 **AI 분석** 패널의 「API 키 설정」을 펼칩니다.
3. 키를 붙여넣고 「키 저장」을 누릅니다. 키 삭제는 「키 삭제」입니다.

키는 이 브라우저의 `localStorage` 항목 `app10-ai-key`에만 저장됩니다. 서버가 없으므로 이 앱은 키를 보관하거나 다른 곳으로 보내지 않으며, 저장된 키는 `api.anthropic.com` 요청에만 쓰입니다. 공용 PC에서는 사용 후 키를 삭제하세요.

### 보내는 내용

AI에는 **연도별 합계 숫자(수입, 경비, 순수입, 적립률, 적립 목표, 원천징수 누계, 부족분, 남은 달 수)와 수입 상위 3개 거래처 이름**만 보냅니다. 거래처 이름은 줄바꿈과 제어문자를 지우고 40자로 줄입니다. 날짜·메모·개별 금액은 보내지 않습니다. 모델이 돌려준 텍스트는 `textContent`로만 표시하며 HTML로 해석하지 않습니다.

AI 분석은 추정치이며 세무 신고를 대신하지 않습니다.

## 계산 방식

- 순수입 = 수입 합계 − 경비 합계
- 적립 목표 = max(0, 순수입) × 적립률
- 원천징수 누계 = 원천징수 체크된 수입 × 3.3%
- 추가 적립 필요 = max(0, 적립 목표 − 원천징수 누계)

이 계산은 **추정치**입니다. 실제 세액은 소득공제, 세액공제, 누진세율, 기납부 세액 등에 따라 달라집니다. 신고 전에는 세무 전문가나 국세청 안내를 확인하세요.

## 실행

빌드 과정이 없습니다. 정적 호스팅에 올리거나, 로컬에서는 간단한 서버로 여세요.

```bash
python3 -m http.server 8080
# http://localhost:8080 접속
```

ES 모듈을 쓰므로 `index.html`을 파일 경로(`file://`)로 직접 열면 브라우저가 스크립트를 막습니다.

데이터는 이 브라우저의 `localStorage`(키 `taxreserve-v1`)에만 저장되며 서버로 전송되지 않습니다.

## 테스트

Node 18 이상에서 실행합니다.

```bash
npm test
```

`logic.js`의 계산 함수, CSV 생성, AI 프롬프트 작성·응답 검증·기본 분석을 `node:test`로 검증합니다. 네트워크 호출은 테스트하지 않습니다.

## 파일 구조
