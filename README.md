# 프롬프트 보관함 (Prompt Vault)

변수(`{{이름}}`)가 있는 AI 프롬프트를 보관하고, 값을 채워 바로 복사하는 정적 웹 앱. 빌드 단계 없음, 외부 스크립트 없음, 외부 폰트 없음.

- 실행: `python3 -m http.server 8013` 후 http://localhost:8013 접속
- 테스트: `node --test` (Node 22 기준, `tests/` 아래 `*.test.js` 자동 탐색)
- 구조: `logic.js` = 순수 함수(검증, 변수 추출, 기본값, 통계, 검색/정렬, 복제, Markdown 변환, 가져오기 병합), `app.js` = DOM 렌더링과 이벤트만 담당
- 데이터는 브라우저 localStorage(`pv-prompts-v1`)에만 저장됩니다. JSON 내보내기/가져오기로 백업하세요.

## 기능

**작성과 관리**
- 프롬프트 등록, 수정, 삭제 (제목 80자, 본문 8,000자, 태그 최대 12개 제한)
- 복제: 기존 프롬프트를 "(사본)"이 붙은 새 항목으로 복사
- 즐겨찾기: 목록 맨 위에 고정, 즐겨찾기만 보기 필터
- 태그: 쉼표로 입력, 태그 칩으로 필터 (개수 표시)
- 여러 개 선택 후 한 번에 삭제

**변수 채우기와 복사**
- `{{변수}}` 자동 감지, 변수별 입력 칸 생성 (긴 이름은 여러 줄 입력)
- 변수 기본값: 수정 화면에서 `이름=값` 형식으로 지정하면 입력 칸이 미리 채워짐
- 실시간 미리보기, 채워진 값 강조 표시
- 글자 수와 토큰 추정치 표시 (한글은 글자당 약 1토큰, 영문은 4글자당 약 1토큰으로 어림한 값)
- 클립보드 복사 시 토스트 알림과 버튼 상태 표시, 사용 횟수와 최근 사용 시각 기록

**내보내기와 가져오기**
- 전체 JSON 내보내기 / 가져오기 (중복 id는 건너뜀, 형식 오류 항목은 개수로 알려 줌)
- 프롬프트 하나를 Markdown(`.md`) 파일로 내보내기 (제목, 태그, 본문, 변수 목록과 기본값)
- 예시 데이터 5개 불러오기

**탐색과 화면**
- 검색: 제목, 태그, 본문에서 여러 단어로 검색 (`/` 키로 검색창 바로 이동, Esc로 검색어 지우기)
- 정렬: 최근 사용 / 많이 쓴 순 / 최신 등록
- 라이트/다크 테마: 시스템 설정을 따르고, 버튼으로 직접 전환 가능
- 360px 너비부터 가로 스크롤 없이 동작, 키보드 포커스 표시, 동작 줄이기 설정 존중

## 참고

- 기본값, 즐겨찾기, 복제 같은 새 필드는 선택 항목이라 이전 버전에서 저장한 데이터와 호환됩니다.
- 예전 버전의 JSON 백업도 그대로 가져올 수 있습니다.
